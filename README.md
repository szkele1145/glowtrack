# GlowTrack

**See where players have been.** GlowTrack records the movement of whitelisted players on a Minecraft server and renders it as a glowing rainbow ribbon in the world.

![GlowTrack](promo/cover_16x9.png)

## Features

- **Rainbow speed heat** - trail color follows movement speed (blue walking to red sprinting), one color cycle every 3 blocks
- **Wallhack rendering** - trails glow through terrain
- **Timeline replay** - press K, drag to scrub back in time, hover for exact time and coordinates
- **One-click teleport** - jump to any recorded moment, cross-dimension included
- **2D patrol mode** - flatten the day's path onto a plane below you
- **Xaero map overlay** - draws onto Xaero's World Map and Minimap (auto-detected)
- **Auto-save & export** - per-player per-day JSON storage, 7-day default retention
- **OP GUI** - searchable whitelist, live readout, sampling and retention sliders

## Requirements

| | |
|---|---|
| Minecraft | 1.21.1 |
| Loader | NeoForge 21.1.x |
| Xaero's World Map / Minimap | optional (map overlay) |

## Usage

1. Drop the jar into both client and server `mods`
2. Add players to the vanilla whitelist - they are tracked automatically
3. Press **K** or run `/gt` to open the tracker
4. Select a player and start tracking
